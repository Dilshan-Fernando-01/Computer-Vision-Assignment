# Demo

Gradio app: upload a fundus image, get predicted DR stage, confidence score, and a Grad-CAM overlay. Deployed live on Hugging Face Spaces.

## Example images

`examples/` contains 5 real fundus photos (one per DR stage) from the DDR dataset, used so the demo is usable without needing your own fundus photo.

DDR dataset: Li, T., Gao, Y., Wang, K., Guo, S., Liu, H., & Kang, H. (2019). Diagnostic assessment of deep learning algorithms for diabetic retinopathy screening. *Information Sciences*, *501*, 511-522. https://doi.org/10.1016/j.ins.2019.06.011

Original source: [nkicsl/DDR-dataset](https://github.com/nkicsl/DDR-dataset), MIT License, Copyright (c) 2019 nkicsl.
