# Data

This folder holds the DDR dataset locally. Contents are not tracked in git (size) — only this README is.

## To populate this folder

```bash
python scripts/download_ddr_dataset.py        # grading images + labels (~3.0 GB)
python scripts/download_ddr_segmentation.py   # lesion segmentation subset (~970 MB)
python src/datasets/splits.py                 # creates train/val/test CSVs
```

Requires a Kaggle API key at `~/.kaggle/kaggle.json`.

## Structure after download

```
data/raw/
  ddr/
    DR_grading.csv                  12,522 labeled images, grade 0-4
    DR_grading/DR_grading/*.jpg     the images themselves
  ddr_segmentation/
    lesion_segmentation/
      train/ valid/ test/           757 images total
        image/                     the fundus photos
        label/{MA,HE,EX,SE,OD}/    pixel-level masks per lesion type

data/processed/
  splits/
    train.csv  val.csv  test.csv   stratified split, generated by src/datasets/splits.py
```

755 of the 757 segmentation images also appear in the grading set (confirmed by filename comparison) — most images have both a stage label and pixel-level lesion masks, enabling joint training rather than a two-stage approach.
